2026.1.16
	被接收机和陀螺仪硬控了一个晚上，插上陀螺仪接收机就不正常，找了半天，
	发现是陀螺仪结构体变量少定义了4个，导致memcpy把数据copy到了奇怪的地
	方，写的时候一定要细心啊！！！
	
2026.1.17
	调Yaw轴的时候怎么调都超调、抖，自己调了一个下午，最后有学长听到6020的
	声音不对劲，连大疆调参软件看了一下，发现是电机自带电流环的值太大了，调
	小就没问题了。
	
2026.1.21
	加上Pitch轴之后Yaw轴会无端抖动，寻找一天未果，最终发现CAN总线过载导致60
	20收不到数据从而引发抖动。
	再次由于硬件问题硬控自己。
	**TIPS：如果一个总线上多个电机，并且里面有达妙、领控电机等，发现其他电机
	 *之前正常，后面不正常的话就先把后面加上的电机注释掉再看，如果没问题了就
	 *怀疑是不是导致总线过载；因为总线过载真的很难发现**
	
		***********解决办法：降低电机CAN总线发送频率**********
	
2026.1.30
	准备给操作手练云台，但是云台突然疯了，直接给机械限位干断了（当心机械伤人、、）
	排查后发现是陀螺仪数据线出问题，更换即可解决。（这件事情告诉我们一定要写心跳
	检测并且好好利用！）

2026.1.22
	由于达妙电机上电后需要使能才能正常工作，不像大疆那样直接发就能工作；因此新增初
	始化模式：不断给达妙发送使能报文，直到达妙反馈Err标志位变为使能状态0x01后再失
	能并退出初始化状态
	
2026.2.3
	2006三摩擦轮因为劲太小，当有弹丸卡在摩擦轮和机械限位之间时会导致摩擦轮无法开启，
	进而导致整场比赛无法打弹；新增摩擦轮卡弹状态，当摩擦轮开启后无法正常旋转时，同
	时反转摩擦轮和拨盘，一段时间后再正转，尝试把弹丸强行挤出（可行，虽然效率较低，
	但也好过没有）
		
2026.2.6
	由于串口有小概率初始化失败（不知道是主控有问题还是我写小零食了）导致云台无法正
	常使用，于是新增键鼠模式下长按X进行软件复位
		
2026.2.8
	操作手反馈在低弹频下会出现发弹延迟高的情况，遂将连发模式由速度环改为单发模式同
	款角度环，删除了射击模式切换时的角度归零，增加键鼠模式下长按R重置拨盘角度以降低
	发弹延迟。
